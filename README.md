# w3-demo — 10주 개발 클래스 · 배포 실습용

수업(8/20)에서 서버에 올려볼 **작은 앱**입니다 — **AI 프로필 사진관**.

⭐ **이 앱에는 진짜 AI가 없습니다. 그게 요점이에요.**
사진을 올리고 "생성"을 누르면… **올린 사진이 그대로 나옵니다.**
만들기 전에 **먼저 올려서, 사람들이 신청을 하는지부터** 보는 방식을 그대로 따라 한 화면입니다.

| 파일 | 뭐냐 |
|---|---|
| `app.py` | 서버. 첫 화면을 그려주고, 신청을 파일에 적습니다 (**설치할 것 없음**) |
| `index.html` | 실제 화면. **여기를 고치면 내 사이트가 됩니다** |
| `img/` | 화면에 쓰는 인물 사진 (AI로 만든 이미지) |
| `test_app.py` | 다섯 줄짜리 검사. *화면에 그 문구가 들어 있나* 만 봅니다 |
| `.github/workflows/ci.yml` | 올릴 때마다 **자동으로** `test_app.py`를 돌려주는 설정 |

> 💡 `.github` 폴더는 점(`.`)으로 시작해서 `ls`에는 안 보입니다. 없는 게 아니에요.
> 💡 신청자 이름은 `waitlist.txt`에 쌓입니다 — **앱을 갈아끼워도 이 파일은 남습니다.**

화면은 세 장입니다. **랜딩 → 사진 올리기 → 신청 완료.**

---

## ✉️ 신청이 들어오면 내 메일로 받기 (해도 되고, 안 해도 됩니다)

설정하면 누가 신청할 때마다 **내 Gmail로 알림**이 옵니다. 안 하면 `waitlist.txt`에만 쌓이고,
앱은 똑같이 잘 돌아갑니다.

### ⚠️ 먼저 — 주소와 비밀번호를 코드에 적지 마세요

이 코드는 GitHub에 올라가고, **올라간 순간 전 세계가 봅니다.** 봇이 몇 분 만에 긁어가요.
그래서 값은 **코드 밖**에 둡니다. 수업에서 말한 *"현관에 붙여둔 열쇠"* 가 딱 이 얘기입니다.

### ① Gmail 앱 비밀번호 만들기 (한 번만)

Google 계정 → **보안** → **2단계 인증**을 켠 다음 → **앱 비밀번호** → 16자리를 받습니다.
⚠️ **평소 쓰는 Gmail 비밀번호로는 안 됩니다.** 2단계 인증을 켜야 이 메뉴가 보여요.

### ② 앱을 켤 때 값을 같이 준다

**맥 · 리눅스 (서버에서도 이대로)**

```bash
MAIL_TO=나@gmail.com MAIL_FROM=나@gmail.com MAIL_APP_PASSWORD=앱비밀번호16자리 python3 app.py
```

**윈도우 (PowerShell)**

```powershell
$env:MAIL_TO="나@gmail.com"; $env:MAIL_FROM="나@gmail.com"; $env:MAIL_APP_PASSWORD="앱비밀번호16자리"
python3 app.py
```

켜질 때 터미널에 `신청 알림 메일: 켜짐 → 나@gmail.com` 이 뜨면 된 겁니다.
(안 하면 `꺼짐 (환경변수 미설정)`.)

### ③ 확인

신청을 한 번 넣어보세요. 완료 화면에 **✉️ 신청 알림이 메일로 발송됐습니다** 가 뜨고,
메일함에 `[AI 프로필 사진관] 새 신청 — 홍길동` 이 들어옵니다.

> 💡 메일 발송은 **따로 돌아갑니다** — 메일이 늦어도 화면은 바로 넘어가고,
> 메일이 실패해도 신청은 이미 저장돼 있습니다.

## 1칸 — 되돌릴 수 있게 올린다 (각자 해보기)

수업에서 한 건 **"올린다"까지**입니다. 그런데 잘못 올렸을 때 **되돌릴 게 없죠.**
되돌리려면 *돌아갈 어제 것*이 남아 있어야 하고, 그걸 만드는 게 아래 세 칸입니다.

**전부 버튼입니다. 명령어를 칠 일은 없습니다.**

### ① 가입 — GitHub 계정 만들기

[github.com](https://github.com) → Sign up. 이메일·비밀번호·아이디만 있으면 됩니다.

### ② 리포 — 이 저장소를 내 것으로 복사

이 페이지 위쪽 초록색 **`Use this template`** → **`Create a new repository`**

- 이름은 `w3-demo` 그대로 두셔도 됩니다
- **`Public`** 으로 두세요 (무료로 ③이 돌아갑니다)
- ⚠️ **Fork를 쓰면 안 됩니다** — 포크는 ③이 기본으로 꺼져 있어서 아무 일도 안 일어나요

### ③ 테스트 — 한 줄 고치고 올려보기

내 저장소에서 `index.html` → 연필(✏️) 아이콘 → 제목 줄에 **내 이름을 붙여** 봅니다.

```html
<h1>나를 닮은 AI 프로필 — 홍길동 사진관<br><em>사진관에 간 것처럼</em></h1>
```

아래 **`Commit changes`** → 바로 위 **`Actions`** 탭으로 가보세요.

🟢 **초록불**이 뜹니다. *내가 시키지 않았는데* 기계가 알아서 돌린 겁니다.

### ③-2 이번엔 일부러 틀려보기 ⭐

같은 방식으로, 이번엔 **`나를 닮은 AI 프로필` 이라는 말을 아예 지워** 봅니다.

```html
<h1>홍길동 사진관<br><em>사진관에 간 것처럼</em></h1>
```

🔴 **빨간불**이 뜹니다. `test_app.py`가 보는 게 딱 그 한 마디거든요
(`app.py`의 `HEADLINE`에 적혀 있습니다).

**이 칸에서 제일 중요한 게 이겁니다** — 사람이 보기 전에 기계가 먼저 걸러줍니다.
그래서 **틀린 게 서버까지 못 갑니다.** 확인했으면 이름 붙인 버전으로 되돌려 두세요.

### ④ 패키지 — 되돌릴 물건이 생기는 자리

초록불이 뜬 실행을 클릭 → 맨 아래 **Artifacts** 에 `w3-demo-1` 같은 **zip**이 매달려 있습니다.
내려받아 보세요.

**이게 "도시락"입니다** — 그때 잘 돌아가던 상태를 **그대로 굳혀서 번호를 붙여 보관**한 것.
잘못 올렸을 때 되돌린다는 건, **이 번호의 zip을 다시 꺼낸다**는 뜻이에요.

> ⭐ **패키지가 없으면 롤백은 성립하지 않습니다.** 돌아갈 어제 것이 없으니까요.
> 수업에서 손으로 올린 건 도시락이 없는 상태였고, 그래서 지우면 그걸로 끝이었습니다.

### ⑤ 배포 — 이번엔 **내** 저장소에서 받아오기

서버에 다시 들어가서, 강사 것 말고 **내 주소**로 받아옵니다.

```bash
git clone https://github.com/<내-아이디>/w3-demo.git
cd w3-demo
python3 app.py
```

**바꿀 건 `<내-아이디>` 하나뿐입니다.**

## 그래서 네 칸이 뭐였나

| 칸 | 어디서 도나 | 내 것으로 하면 |
|---|---|---|
| **리포** | GitHub — **보관만** 합니다. 여기선 안 돌아가요 | ② |
| **테스트** | GitHub이 **잠깐 빌려주는 컴퓨터**. 끝나면 사라집니다 | ③ |
| **패키지** | 같은 컴퓨터에서 만들어 **번호 붙여 보관** | ④ |
| **배포** | ⭐ **내 서버** — 계속 켜져 있는 건 여기 하나뿐 | ⑤ |

> "올린다"는 말이 세 번 나오는데 **전부 다른 컴퓨터**입니다.
> GitHub에 올린다(보관) · 빌린 컴퓨터에서 돌려본다(검사) · 내 서버에 올린다(서비스).
